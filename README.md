# Memory Game 

A browser-based memory card game built with TypeScript, SCSS, and Vite.

##  About the Project

Memory Game is a two-player matching game. Players take turns flipping cards to find matching pairs and earn points.

The player with the highest score wins. If both players have the same score, the game ends in a draw.

##  Features

* Two selectable themes: Code Vibes and Gaming
* Two players: Blue and Orange
* Three board sizes: 16, 24, or 36 cards
* Interactive card-flipping gameplay
* Score tracking and turn management
* Winner and draw screens
* Animated transitions and hover effects

##  Technologies

* HTML5
* SCSS
* TypeScript
* Vite

##  Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

Clone the repository and open the project folder.

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in your terminal.

### Production Build

```bash
npm run build
```

[Play Memory Game](https://enes-kurt.developerakademie.net/memory/)

##  How to Play

1. Click **Play** on the home screen.
2. Select a game theme.
3. Choose the starting player.
4. Select a board size.
5. Click **Start**.
6. Take turns revealing two cards.
7. Find matching pairs to score points.
8. The player with the most points wins.
